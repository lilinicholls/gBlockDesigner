gBlock Designer

Design synthetic DNA from one or more primers, then BLAST it and screen it against manufacturing parameters. If you use this software, please cite it: Nicholls (2026).

1. Design

Primers

Add every primer you're using individually, then build pairs.

Primers can contain degenerate bases, but gBlocks cannot. Degenerate bases are automatically substituted using IUPAC codes , favouring A/T over G/C. Turn it off to choose the base at every degenerate position.

Primer pairs

Select pairs from the list above and choose the fragment length for each pair (not counting the primers themselves).

Probe (optional)

The probe is inserted exactly as typed (plain A/C/G/T only, no degenerate codes) at a specific place within one primer pair's region. "Start position" counts from the right after that pair's forward primer ends. If the start position is left blank, the probe is automatically centred.

Choose bases for degenerate positions

Automatic substitution is off. Pick a base for every degenerate position below, then confirm to design the gBlock.

3. NCBI BLAST

Searches NCBI's public database for existing sequences that match your designed fragment. This can take 30 seconds to several minutes.

4. Manufacturing complexity check

Checks your sequence for the same kinds of problems IDT's ordering tool looks for: unusual GC content, repeated letters, repeated chunks, and hairpins.

Before you order: this is a simplified stand-in for IDT's own screening tool, not a replacement for it. Always paste your final sequence into IDT's gBlocks entry tool to get their official read before ordering.
