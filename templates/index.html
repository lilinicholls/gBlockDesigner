gBlock Designer

Design a synthetic gBlock from one or more primers, then BLAST it and screen it against IDT.

1. Design

Primers

Add every primer you're using, once each. If two pairs share a primer (like one reverse primer shared by two forwards), it only goes here once — you'll pick it again below when building each pair.

Primers can contain IUPAC degenerate codes (R, Y, S, W, K, M, B, D, H, V, N) — but a gBlock has to be one exact sequence, so each one gets resolved to a single real base. Left on, this happens automatically (favouring A/T over G/C). Turn it off to choose the base yourself for every degenerate position instead.

Primer pairs

Each pair needs a forward and a reverse primer (picked from the list above) and a fragment length: the length of sequence strictly between that pair's own two primers (not counting those two primers themselves — though it does count any other primer that happens to sit in between). Gaps between primers are worked out automatically from these.

Choose bases for degenerate positions

Automatic substitution is off. Pick a base for every degenerate position below, then confirm to design the gBlock.

3. NCBI BLAST

Searches NCBI's public database for existing sequences that match your designed fragment. This can take 30 seconds to several minutes.

4. Manufacturing complexity check

Checks your sequence for the same kinds of problems IDT's ordering tool looks for: unusual GC content, repeated letters, repeated chunks, and hairpins (spots where the DNA could fold back on itself). This runs entirely on your own computer — nothing is sent to IDT.

Before you order: this is a simplified stand-in for IDT's own screening tool, not a replacement for it. Always paste your final sequence into IDT's gBlocks entry tool to get their official read before ordering.
